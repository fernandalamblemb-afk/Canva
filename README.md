# Canva

Canva agent skills for Claude Code, vendored from
[canva-sdks/canva-skills](https://github.com/canva-sdks/canva-skills) (commit `232e205`, Apache-2.0).

Skills live in `.claude/skills/` and load automatically in Claude Code sessions opened on this repo.
They use the Canva MCP connector (`https://mcp.canva.com/mcp`).

Included: canva-agent-guide, canva-autofill, canva-brand-check, canva-bulk-create, canva-cli,
canva-design-feedback, canva-edit-design, canva-implement-feedback, canva-instagram-post,
canva-resize-for-social-media.
